# Voice Agent Stack

Learning project: open-source voice I/O for AI agents, built on
[Voicebox](https://github.com/jamiepine/voicebox). Agents get two
primitives — **speak** (TTS through cloned/preset voices) and **listen**
(STT through Whisper) — exposed over MCP so any MCP-aware client can
use them. A pipecat-based bot adds real-time voice conversation over
WebRTC via LiveKit.

## Architecture

```
┌─ Podman host (loopback-only) ─────────────────────────────────┐
│                                                                │
│  voicebox:17600 ─── GPU TTS engine (kokoro, chatterbox, ...)   │
│  livekit:7880   ─── WebRTC signaling + media                   │
│  token-mint:17602 ─ JWT minter for browser/mobile              │
│  whisper-stt:8001 ─ GPU STT (faster-whisper large-v3-turbo)    │
│  glados-tts:5001 ── Piper TTS (persistent session, fallback)   │
│  llama-small:19091 ─ LLM (Qwen3-8B via queues proxy)          │
│                                                                │
│  pipecat bot ─── VAD → STT(GPU) → LLM → TTS(kokoro) → LiveKit │
└────────────────────────────────────────────────────────────────┘
```

**GPU budget** (RTX 4060 Ti 16GB): llama-server 7G, whisper-stt 2.25G,
voicebox 0.9G, misc 0.5G — ~5.4GB headroom.

**Measured latencies** (warm): STT ~0.19s, LLM ~0.3-0.7s, TTS ~40ms
(kokoro) / ~160ms (piper), end-to-end ~2-3s.

## Components

### Voicebox (upstream, unmodified)

Headless podman container running the Voicebox desktop app. Provides
7 TTS engines (kokoro, chatterbox, chatterbox_turbo, qwen, luxtts, tada,
qwen_custom_voice), Whisper STT, and a REST API at :17600. Never
exposed beyond loopback.

### Wrapper MCP server (`services/voice-mcp/`)

FastMCP server exposing `say`, `voices`, `listen` as MCP tools. Typed
REST client → Voicebox. Runs stdio for agent integrations (opencode,
Claude Code) or HTTP for the pipecat bot.

### GPU whisper-stt (`whisper-stt/`)

Standalone FastAPI service running faster-whisper large-v3-turbo in
fp16 via CUDA. OpenAI-compatible `/v1/audio/transcriptions` endpoint
at :8001. Language hint (`OPENAI_STT_LANGUAGE`) prevents hallucinated
transcriptions on short/noisy fragments.

### Persistent piper TTS (`~/Projects/mcp/glados-tts/`)

FastAPI service wrapping `PiperVoice.load()` + `synthesize()` for
streaming WAV synthesis. Voice models at `~/Projects/mcp/glados-tts-models/`.
Runs at :5001. Used as fallback when voicebox is unavailable.

### Pipecat bot (`telephony/pipecat-bot/`)

Real-time voice agent built on pipecat. Pipeline:
VAD → STT → LLM → TTS → LiveKit transport.

- **STT**: GPU whisper-stt via `OpenAIBatchSTTService`
- **LLM**: Qwen3-8B via queues proxy (OpenAI-compatible)
- **TTS**: voicebox/kokoro via `VoiceboxTTSService`
- **Context**: auto-summarization via pipecat's `LLMAutoContextSummarization`
- **Backchannels**: pre-rendered acknowledgment clips ("mm-hmm", "right",
  etc.) injected during LLM thinking for natural turn-taking
- **Turn detection**: LocalSmartTurnAnalyzerV3 (semantic end-of-turn)

### Backchannels (`backchannels/`)

Pre-rendered audio clips generated by `scripts/backchannel-bank.py`.
Auto-regenerates when `VOICEBOX_PROFILE_ID` changes (sentinel
`.meta.json`). Supports kokoro and chatterbox_turbo engines.

## Quick start

```sh
# Full stack (voicebox + livekit + bot)
./scripts/stack-up.sh

# Voice + STT services only (whisper-stt + glados-tts)
docker compose -f docker/voicebot-stack.yml up -d

# Pipecat bot (host-side, needs voicebot-room in LiveKit)
VOICEBOT_STT_PROVIDER=openai VOICEBOT_TTS_PROVIDER=voicebox \
  OPENAI_STT_BASE_URL=http://127.0.0.1:8001 OPENAI_STT_LANGUAGE=en \
  uv run --directory telephony/pipecat-bot voicebot

# Verify end-to-end
./scripts/smoke-test.sh

# Play latest generated audio
./scripts/play-latest.sh
```

## Commands

```sh
# Full stack
./scripts/stack-up.sh            # voicebox + livekit + bot
./scripts/stack-up.sh down

# Voicebot services (whisper-stt + glados-tts)
docker compose -f docker/voicebot-stack.yml up -d
docker compose -f docker/voicebot-stack.yml down

# Wrapper MCP
uv run --env-file ../../.env --directory services/voice-mcp voice-mcp

# Pipecat bot (host-side)
uv run --directory telephony/pipecat-bot voicebot

# Regenerate backchannels
./scripts/backchannel-bank.py --engine kokoro --profile "Bella" --force

# Tests
uv run --directory services/voice-mcp pytest -q
uv run --directory telephony/pipecat-bot pytest -q

# Verification
./scripts/smoke-test.sh
./scripts/mcp-inspect.sh
./scripts/play-latest.sh
```

## Environment

Secrets and config live in `.env` (gitignored). See `.env.example` for
every variable. Key settings:

| Variable | Default | Purpose |
|---|---|---|
| `VOICEBOX_PROFILE_ID` | — | Default voice for bot TTS |
| `VOICEBOT_STT_PROVIDER` | `voicebox` | STT backend: `voicebox`, `openai`, `local` |
| `VOICEBOT_TTS_PROVIDER` | `voicebox` | TTS backend: `voicebox`, `piper` |
| `OPENAI_STT_BASE_URL` | `http://127.0.0.1:8001` | GPU whisper-stt endpoint |
| `OPENAI_STT_LANGUAGE` | — | Language hint for whisper (e.g. `en`) |
| `OLLAMA_MODEL` | — | LLM model name (Qwen3-8B) |
| `OLLAMA_BASE_URL` | — | LLM endpoint (queues proxy) |
